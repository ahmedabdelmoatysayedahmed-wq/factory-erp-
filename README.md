# نظام إدارة المصنع (Factory ERP)

نظام ويب بالعربي لإدارة المصنع، بيشتغل من أي متصفح على الكمبيوتر أو الموبايل.

## الأقسام
| القسم | المحتوى |
|---|---|
| لوحة التحكم | الحضور، إنتاج اليوم، الهالك، التوقفات، حالة الماكينات، أوامر التشغيل، تنبيهات المخزون وصيانة الإسطمبات |
| الإنتاج اليومي | تسجيل إنتاج كل موظف على كل ماكينة/إسطمبة/أمر تشغيل (سليم، هالك، ساعات، توقفات) |
| أوامر التشغيل | الكمية المطلوبة، ونسبة الإنجاز بتتحسب تلقائياً من الإنتاج اليومي |
| الماكينات / الإسطمبات / الأصول | سجل كامل. الإسطمبات بتحسب عدد الضربات تلقائياً وبتنبّه قبل ميعاد الصيانة |
| المواد الخام وحركات المخزن | وارد / صرف / تسوية، والرصيد بيتحسب تلقائياً، ومينفعش تصرف أكتر من الرصيد |
| الموظفين / الحضور والانصراف / الإجازات | شاشة حضور يومية لكل الموظفين مرة واحدة، وطلبات إجازة بحالة موافقة |
| تقارير الإنتاجية | لكل موظف: الإنتاج، الهالك، قطعة/ساعة، تحقيق المستهدف، الحضور والغياب. لكل ماكينة: الكفاءة والإتاحية |
| المستخدمين والصلاحيات | 6 أدوار: مدير النظام، مدير المصنع، مشرف إنتاج، أمين مخزن، شؤون الموظفين، مشاهدة فقط |

## التشغيل
```bash
npm install
npm start          # http://localhost:3000
```
أول دخول: `admin` / `admin123` — **غيّر كلمة المرور فوراً** من "كلمة المرور" أعلى الصفحة.

متغيرات البيئة: `PORT`، `SESSION_SECRET` (لازم تتغير في التشغيل الفعلي)، `DB_FILE` (افتراضياً `data/factory.db`).

## التقنيات
Node.js + Express + SQLite (better-sqlite3) + EJS. قاعدة البيانات ملف واحد في `data/` — خد منه نسخة احتياطية بانتظام.
